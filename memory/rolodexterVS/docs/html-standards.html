File Naming Conventions

  • Session Logs: YYYY-MM-DD-session-log.html
  • Task Files: YYYY-MM-DD-task-name.html
  • Reports: YYYY-MM-DD-report-type.html
  • Debriefs: YYYY-MM-DD-debrief-topic.html

Directory Organization

memories/
├── sessions/YYYY/MM/         # Daily session logs
├── debriefs/YYYY/MM/        # System debriefs
└── archived/YYYY/           # Archived content

tasks/
├── active/                  # Current tasks
├── completed/YYYY/MM/       # Completed tasks
└── blocked/                 # Blocked tasks

reports/
├── weekly/YYYY/MM/         # Weekly summaries
├── issues/                 # Issue tracking
└── metrics/                # System metrics

Standard CSS Classes

  • documentation-page - Base class for all pages
  • memory-content - Main content wrapper
  • status-block - Status information container
  • attribution-info - Attribution details
